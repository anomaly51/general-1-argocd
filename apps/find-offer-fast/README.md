# Find Offer Fast

Production backend for group IT learning on general-1.

- Public API: https://find-offer-fast.api-api-api.com
- Source: https://github.com/anomaly51/find-offer-fast-backend
- Android: https://github.com/anomaly51/find-offer-fast-android
- Credentials: Vault `kv/apps/find-offer-fast/env`, synchronized by VSO.
- PostgreSQL uses retained NFS storage. RabbitMQ uses a dedicated user and vhost on the shared cluster.
