Hermes Mail

A personal Gmail and Google Calendar assistant running in its owner's Kubernetes cluster. Hermes can search and read mail, prepare drafts, send requested replies, manage messages and labels, and view, create and update meetings through Google APIs.

This is an information page. The assistant's web interface is private; this website provides no access to mail or to the agent.

Privacy · Terms of use · Contact

Privacy

Hermes Mail is for the owner's explicitly connected Google accounts. It requests full Gmail access, including reading, composing, sending and permanently deleting mail, to perform the owner's instructions. When Calendar is connected, it can read the calendar list and access events, including meeting details, guests, responses and links. Google's event permission covers creation, changes and deletion; the assistant exposes viewing, creation and updates. Changes can send Google invitations or update notifications to guests. It does not receive Chrome cookies, Google passwords, Drive access or calendar-sharing permissions.

OAuth refresh credentials are stored in the owner's Vault and mounted into the agent. Mail and calendar content needed for a request can be processed by the configured OpenAI model under the owner's account settings. Replies requested through Telegram also pass through Telegram. Chat history and tool results may remain in the agent's persistent storage until the owner deletes them. This static information page stores no mail or events and uses no analytics or cookies.

Mail is not sold or used by this application for advertising or model training. Hermes Mail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Access can be revoked in Google Account connections. The owner can remove stored OAuth credentials from Vault and delete retained agent history. Contact the operator at catprogrammer.vlad@gmail.com for access or deletion requests.

Terms of use

This is a personal, private tool, not a public mail service. Use it only with accounts you own or are authorized to manage. Review AI-generated content before requesting delivery. The owner remains in control of mailbox operations and can disconnect any account at any time. The tool is provided as-is, without a guarantee of availability or accuracy.
