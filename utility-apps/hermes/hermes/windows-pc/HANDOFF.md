# Текст для нового чата Codex на Windows

Я работаю на своём втором ПК с Windows. Он в одной локальной сети с моим
Kubernetes-кластером General. Hermes уже запущен в кластере. Нужны Computer Use
на моём текущем рабочем столе Windows с уже открытыми окнами, живое превью
основного монитора внутри Hermes и запуск Codex под моей подпиской ChatGPT.

Клонируй или обнови https://github.com/anomaly51/general-1-argocd. Прочитай
AGENTS.md и utility-apps/hermes/hermes/windows-pc/README.md. В репозитории
уже есть Helm-конфигурация с `windowsPc.enabled: false`, панель просмотра,
Setup.ps1 и шаблон SSH. Используй их. Windows-часть запускай из текущего
интерактивного сеанса под моим Windows-аккаунтом. Покажи мне запрос на вход
в ChatGPT или повышение прав, когда он появится.

1. Проверь LAN IPv4, пользователя, состояние OpenSSH, Codex CLI и Cua Driver.
   Поставь недостающие компоненты из официальных источников. OpenSSH должен
   подключать к Windows-пользователю с тем же SID, под которым запущен Cua Driver.
2. Выполни Setup.ps1 -EnableDesktop и запусти codex login, если CLI ещё
   не вошёл. Подключи отдельный публичный SSH-ключ Hermes, выданный оператором
   кластера. Передай оператору LAN IP, имя SSH-пользователя, публичный ключ хоста
   и отпечаток. Храни реальные параметры машины, ключи и токены вне Git.
3. При наличии доступа к GitOps и Vault выполни кластерные шаги из README.
   Кластерные изменения применяй только коммитом и Argo CD. Если Vault или
   SSH-ключ недоступны, проверь Windows-часть и укажи, что осталось оператору.
4. Открой внутренний Hermes. В панели **Windows PC** запусти просмотр, попроси
   Hermes через MCP открыть Калькулятор и проверь окно в текущем Windows-сеансе.
   Проверь Windows Codex отдельной задачей на чтение. Сообщи результат проверок.
